## 本阶段完成内容

- 将购物约束拆分为价格、品牌、SKU 离散属性、数值条件、必需语义特征和排除语义特征。
- 从当前 Catalog 构建跨品类 SKU taxonomy，在同一个 SKU 上联合应用价格与规格条件。
- 保留原始商品 JSON 作为唯一事实源，匹配商品卡片只输出真实 SKU、价格、品牌和图片。
- 证据模型改用强制 `submit_evidence_assessment` Function Calling；工具参数继续经过严格 Pydantic、商品 ID、condition ID 和证据 ID 校验，首次可纠正错误重试一次。
- 固定三态宽松准入：`supported` 与 `unknown` 保留，`contradicted` 淘汰；当前排序仍使用 `rerank_score`，不提前实现评分系统。
- 增加意图、编译约束、证据输入和证据模型原始参数的单行诊断日志。
- 测试客户端在正常结束和客户端错误时输出单轮总耗时。
- 将一轮内最多十个独立证据模型请求从串行改为最多五个并发；并发限制不跨请求共享，完成顺序不改变候选顺序，任一失败会取消并清理同轮其他任务。

## 已知问题与后续边界

- “防晒精华”等同时包含多个合法子类词的复合商品短语，意图模型仍可能选择错误的中心子类。
- `unknown` 候选允许准入，但最终生成模型目前可能将未明确验证的条件表述为已经满足，例如把 `unknown` 的手机统一描述为“均为非折叠屏”；后续需要单独设计状态感知的回复事实边界。
- 单轮总耗时仍可能超过二十秒。证据并发已经生效，但当前没有意图、检索、重排、证据批次和生成阶段的独立耗时，暂不继续提高并发上限。
- `supported` 与 `unknown` 的排序权重和综合评分系统不属于本阶段。
- 多轮条件继承、澄清追问、图片理解、持久化和交易能力不属于本阶段。

## 当前状态

本阶段在现有范围内停止继续扩展并提交为检查点。功能文档与代码保持“开发中”，下一阶段应先针对上述已知问题创建独立设计，再修改准入后的回复表达、评分或性能链路。
