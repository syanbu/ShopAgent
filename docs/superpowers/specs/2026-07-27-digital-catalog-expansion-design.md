# 数码电子商品数据扩充设计

## 背景与目标

当前数据集共有 100 款商品，其中数码电子 25 款。数码电子中的智能手机有
10 款，真无线耳机只有 2 款。用户完成首轮耳机推荐后继续询问“还有别的吗”
时，系统会排除已经展示的两款商品，因此没有剩余候选。

本次只扩充静态商品事实与本地图片，不改变搜索、推荐、对话或 API 行为。完成后：

- 商品总数由 100 增至 112；
- 数码电子商品由 25 增至 37；
- 智能手机由 10 增至 14；
- 真无线耳机由 2 增至 10。

## 范围

### 包含

- 新增 4 款智能手机和 8 款真无线耳机；
- 为每款商品提供完整 SKU、营销介绍、FAQ 和正反面用户评价；
- 为每款商品生成一张本地 AI 商品主图；
- 使用现有离线索引流程将新增商品写入派生的 Qdrant 文本索引；
- 更新现行文档、数据规模断言和相关测试。

### 不包含

- 智能手表、移动电源或其他新子类；
- Google 图片或品牌官网图片下载；
- 商品 Schema、API、工作流和检索算法调整；
- 真实库存、促销、购买链接或实时价格；
- 改写历史计划、历史状态和历史设计中的验收快照。

## JSON 数据设计

每款商品使用当前 `ecommerce_agent_dataset/2_数码电子/data/` 下的单文件 JSON
结构：

- `product_id`、`title`、`brand`、`category`、`sub_category`；
- `base_price` 和指向本地文件的 `image_path`；
- 3–6 个 SKU，每个 SKU 有唯一 `sku_id`、规格属性和价格；
- 一段 `marketing_description`；
- 3 条 `official_faqs`；
- 5 条 `user_reviews`，同时包含优点、缺点和中性体验。

所有事实必须内部一致：

- 标题、SKU、详情、FAQ 和评价不能出现互相冲突的容量、颜色、功能或价格；
- 手机使用现有可规范化的“存储”“版本”“颜色”等 SKU key；
- 耳机使用现有可规范化的“版本”“颜色”等 SKU key；
- 商品标题必须显式包含“手机”或“真无线蓝牙耳机”，保证类别查询文本清晰；
- 不写库存、优惠券、活动价、购买链接或数据集中无法验证的外部事实。

## 图片设计

每款商品生成一张独立的 AI 电商主图，共 12 张：

- 方形构图，统一浅色或白色背景，主体居中；
- 手机同时展示正面屏幕和背面机身；
- 耳机同时展示左右耳塞和充电盒；
- 不生成品牌 Logo、型号、参数或其他文字；
- 不模仿某张受版权保护图片的构图；
- 颜色和外观与对应 JSON 的主推 SKU 保持一致。

图片保存到 `ecommerce_agent_dataset/2_数码电子/images/`，名称采用
`<product_id>_live.jpg`，JSON 中保存相对于数据集根目录的路径。输出需归一化为
RGB JPEG；图片无法生成、无法解码或路径校验失败时，该商品不进入最终数据集。

## 索引与运行时数据流

原始 JSON 和本地图片继续作为唯一事实源，Qdrant 只是可重建派生索引：

1. `ProductCatalog` 启动时加载 112 份 JSON；
2. 现有 taxonomy 从商品数据自动读取品牌、类目、子类和 SKU 值；
3. 运行 `python -m shop_agent.cli.index_products`，幂等写入新增商品文本 Chunk；
4. 在线搜索从 Qdrant 召回候选，再回到 Catalog 校验商品、SKU、价格和图片；
5. “还有别的吗”继续使用既有排重逻辑，新数据只增加可供翻页的候选。

本次不删除或重建已有集合，也不修改在线服务契约。

## 校验与测试

### 静态数据校验

- 112 份 JSON 均可解析；
- `product_id`、`sku_id` 全局唯一；
- 所有商品的 `base_price` 等于最低 SKU 价格；
- 112 个 `image_path` 均位于数据集目录内且文件存在；
- 12 张新增图片可解码为 RGB JPEG；
- 新商品只使用 taxonomy 已支持或在同次修改中明确映射的 SKU key；
- 现有全部单元测试通过。

### 行为验收

在索引完成后至少验证：

- “推荐一款手机”可以召回新增手机；
- “推荐一款蓝牙耳机”可以召回新增耳机；
- 连续询问“还有别的吗”时，在商品未耗尽前继续返回新结果；
- 荣耀、三星、一加、Redmi、小米、vivo、OPPO 和索尼品牌筛选可命中对应商品；
- 手机和耳机的价格筛选返回的每个商品均有符合预算的 SKU；
- 商品事件中的标题、品牌、价格、SKU 和图片与 Catalog 原始 JSON 一致。

外部模型或 Qdrant 不可用时，先完成全部离线数据校验和单元测试，并明确记录未执行
的联网验收，不把外部依赖失败误报为数据错误。
